# 🎨 Live Color Detector

A real-time **Live Color Detector** built with **Python** and **OpenCV** that identifies the color at the center of your webcam feed. The application displays the closest named color along with its RGB and HSV values in real time.

---

## 📸 Preview

Place any object in front of your webcam and align it with the center crosshair to instantly detect its color.

---

## ✨ Features

- 🎥 Real-time webcam feed
- 🎯 Center crosshair for accurate color detection
- 🎨 Detects the closest named color
- 🌈 Displays RGB values
- 🖌️ Displays HSV values
- ⚡ Fast and lightweight
- 💻 Simple single-file Python project
- ❌ Press **Q** to quit

---

## 🛠️ Built With

- Python 3
- OpenCV
- NumPy
- Webcolors (optional, for named color detection)

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Gireesh-mlgs/live-color-detector.git
cd Color-Detector
```

Install dependencies:

```bash
pip install opencv-python numpy webcolors
```

---

## ▶️ Usage

Run the application:

```bash
python main.py
```

1. Allow webcam access.
2. Point the center crosshair at any object.
3. The detected color name, RGB, and HSV values will appear on the screen.
4. Press **Q** to exit.
